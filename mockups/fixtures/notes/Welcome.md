# Welcome to Notes

Everything in this folder is a note: the title is the file name, the tile
shows the first lines. Groups are folders -- drag a note onto another one.

## What works here

- **Live markdown**: headings, *emphasis*, `inline code`, [links](https://quickshell.org/docs/)
- Lists, nested
  - like this one
  - and this
- Tasks you can tick
- Colour: <span style="color:blue">blue words</span> and ==highlights==
